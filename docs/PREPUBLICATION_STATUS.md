## 本版明确停用的能力

- 无可靠原子流水的旧分佣写入、兑换码生成与兑换、代理开户充值/分配、结算写入。
- 代理 script/topic/writing 付费生成：未建立可信扣费结算前返回明确不可用。
- 自动化执行和新手奖励领取：保留安全读取/草稿或进度，执行/发奖明确不可用且不得预扣费。
- 自动永久清理用户：保留鉴权预览，永久删除不可用。
- 自动退款：旧接口只有用户和金额，没有唯一扣费凭据，明确拒绝，不能声称已退回。

已盘点 155 个 route 文件的 208 个导出 HTTP 方法，清单见 API_SURFACE.md；这不是全部业务语义或真实数据库逐项验收。

统一入口只允许精确公开方法；维护密钥和签名代理请求由对应处理函数继续验证。新增未知 API 默认要求有效用户会话。会话与角色入口保护不代替处理函数内的所有权检查。

AI 防护采用单进程每用户 20 次/分钟、100 次/天上限、256 KiB JSON、受限图像上传和供应商配置检查。多实例部署必须另接共享额度服务。公开网页读取只处理静态 HTML/文本，DNS 固定、每次重定向检查、15 秒总超时和 2 MiB 内容限制；不运行网页 JavaScript。

共享扣费函数现在在同一条条件更新中修改 credits 和 used_power，并确认返回记录；并发冲突拒绝。本地替身测试通过，实际 PostgreSQL 行为、持久扣费流水及退款幂等仍未验收。勿用于真实充值/商业计费。

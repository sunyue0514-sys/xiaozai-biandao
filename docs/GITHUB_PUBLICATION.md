## 仓库名称

## About 简介

面向短视频内容策划的开源 AI 创作工作台：将客户与产品资料、选题与脚本、参考视频分析、广告文案和素材管理放在同一个 Web 项目中，支持配置自己的数据库与 AI 服务，适合学习和二次开发。

v0.1.0 · 小仔首次开源：从客户资料到短视频脚本的 AI 创作工作台

## 首次发布正文

做内容，写脚本只是其中一步。

在它之前，还要弄清客户做什么、产品卖给谁、哪些卖点值得讲、参考视频有哪些可借鉴的地方。小仔将这些内容策划前期的工作放进一个 Web 项目：客户和产品资料、选题与脚本、参考视频分析、广告文案，以及素材与创作记录。

这次开放源码，希望给需要搭建内容工具的开发者、内容团队和 AI 应用学习者提供一份可以继续修改的项目基础。

### 本次公开包含

- Next.js、React、TypeScript 构建的 Web 页面和业务 API。
- 客户与产品资料、选题与脚本、视频分析、广告文案、素材及创作记录等模块代码。
- 空的环境变量模板、空测试库初始化脚本和独立管理员初始化工具。
- 安装配置、依赖升级、贡献指南、安全说明及第三方许可证声明。
- 324 项自动测试通过记录，以及类型检查和 Windows 兼容生产构建记录。

### 使用前请了解

本项目提供源码，不提供原作者的数据库、账号、客户资料、API Key 或在线服务。你需要使用自己的服务账户配置数据库、AI 网关和需要的视频服务。

当前锁定依赖尚待安全升级，部署前请按文档联网核对、升级和测试。部分缺少可靠资金流水的兑换、分佣、结算及自动退款等功能已明确停用；真实数据库、AI 和浏览器端到端验收仍未全部完成。自动测试通过不等于可以直接用于生产。

欢迎提交可复现的问题、文档改进和代码修复。具体配置、功能范围与限制见 README。

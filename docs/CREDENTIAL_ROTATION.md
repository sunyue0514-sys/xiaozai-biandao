# 凭据清理与撤销记录

此文件不包含任何真实密钥。删除代码中的密钥不代表服务端密钥已经撤销。

| 类别 | 代码处理 | 服务端状态 |
| --- | --- | --- |
| TikHub API Key | 原硬编码值已移除，改为私有环境变量 | 未验证撤销；需要在原服务账户吊销并重新签发 |
| 视频解析 Token | 原硬编码值已移除 | 未验证撤销；需要在原服务账户吊销并重新签发 |
| Coze 调试 JWT | 调试文件与令牌已移除 | 未验证撤销；需要原账户检查有效会话/工作负载凭据 |
| 原默认管理员和个人账号信息 | 已移除；新管理员通过 CLI 单独初始化 | 如旧账号曾实际部署，需在该部署重置密码并注销旧会话 |
| 数据库凭据 | 发布目录只有空的 `.env.example` | 未连接原数据库；不能证明原凭据失效 |

最终源码扫描包括原包中识别出的 5 个敏感字面值，以及 JWT、常见供应商令牌、私钥、数据库密码 URL、敏感配置文件和一般密钥赋值规则。扫描结果只能说明这些规则没有命中，不能证明识别了所有秘密。

本准备包不携带 Git 历史；没有已审查的历史提交可随包发布。未来建立仓库应只导入这个清理后的目录，勿导入原压缩包、原目录或原提交历史。服务侧撤销后，应在私有环境记录撤销时间和旧凭据拒绝结果，不要将这些凭据放入本文件。

当前会话没有这些供应商账户的密钥管理权限，未执行远程吊销，也未使用原包密钥发起付费请求。此项外部操作尚未完成。

## 对源码使用者的说明

本项目不提供原作者的可用 Key。复制 `.env.example` 为 `.env.local` 后，使用自己的服务账户申请并填写凭据；不要将实际值提交进仓库。原 Key 的后台撤销属于原账号安全处理，与是否在开源代码中保留该 Key 是两件事。占位符不会使原 Key 自动失效。

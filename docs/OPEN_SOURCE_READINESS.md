# 源码公开与部署的区别

本版按“公开源码，供学习和二次开发”准备。真实密钥不随代码提供，`.env.example` 保留空配置，使用者填写自己的凭据。源码不附带作者服务、生产数据或通用默认密码。

可以将配置缺失、依赖待升级、服务联调未完成作为明确披露的限制；它们不等于源码不能公开。部署者应按 [SELF_HOSTING.md](SELF_HOSTING.md) 完成升级、配置及验收。原有代码和保留材料的再分发权仍由维护者负责确认。

修复、暂不可用功能和验证证据见 [PREPUBLICATION_STATUS.md](PREPUBLICATION_STATUS.md)。未发布到 GitHub，未声称生产可用。
